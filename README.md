# 🏢 Hotel Network Configuration & Infrastructure Design

This project showcases a production-grade network architecture design and simulation engineered for a multi-floor hotel environment using **Cisco Packet Tracer**[cite: 1]. The architecture focuses on implementing high-performance logical segmentation via **Router-on-a-Stick (Inter-VLAN Routing)**[cite: 1], completely isolating corporate administrative networks, operational staff departments (IT & Marketing), and guest-facing zones to guarantee strict security boundaries and eliminate broadcast storms[cite: 1]. The system features automated IP management using custom **DHCP Server Pools** across edge boundaries[cite: 1], infrastructure security using centralized **WPA2-PSK** authentication on local access points[cite: 1], and dedicated internal web servers hosting localized guest portals[cite: 1]. 

To run this simulation locally, simply clone this repository, ensure you have **Cisco Packet Tracer** installed[cite: 1], open the included `.pkt` topology file, and use the simulation panel to trace active packet traversals, inter-VLAN pings, and automated dynamic IP assignments.
